# Sadak Project (2nd Semester CSIT)

This repository contains a static website developed as part of my second-semester CSIT coursework at Nepathya College. The project focuses on creating a responsive and informative website dedicated to roads and infrastructure in Nepal.

## Project Overview

The Sadak Project aims to provide users with essential information about roads, infrastructure, and related services in Nepal. The website features multiple pages, including:

- **Home Page:** Introduction and overview of the project.
- **About Us:** Information about the project's objectives and team.
- **Photogallery:** A gallery showcasing images related to roads and infrastructure.
- **Karmachari:** Details about the project's staff and contributors.

## Features

- **Responsive Design:** Optimized for various screen sizes, ensuring usability across devices.
- **Multiple Pages:** Includes several pages with navigation links for easy access.
- **Image Gallery:** A dedicated page displaying images related to the project's theme.

## Technologies Used

- **HTML5:** For structuring the content of the website.
- **CSS3:** For styling and layout design.
- **Images:** Various images related to roads and infrastructure in Nepal.

## File Structure

- `main.html`: The main HTML file containing the website's structure.
- `aboutus.html`: Page detailing information about the project.
- `photogallary.html`: Gallery page displaying images.
- `karmachari.html`: Page providing details about the project's staff.
- `main.css`: The primary CSS file for styling the website.
- `images/`: Directory containing image assets used in the website.
